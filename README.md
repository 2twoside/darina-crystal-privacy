# Политика конфиденциальности приложения Darina Crystal

**Дата вступления в силу:** 21 ноября 2026 г.

## 1. Общие положения

Приложение Darina Crystal (далее — «Приложение») не собирает, не хранит и не передает персональные данные пользователей третьим лицам.

## 2. Обработка изображений

Все изображения, загружаемые пользователем для генерации схем выкладки страз, обрабатываются исключительно локально на устройстве пользователя. Изображения не передаются на внешние серверы.

## 3. Сбор технических данных

Приложение не использует аналитические SDK, не собирает IMEI, геолокацию, контакты и иную персональную информацию.

## 4. Платежи

Если в будущем в приложении появятся платные функции, оплата будет осуществляться через встроенную систему расчетов RuStore. Данные банковских карт обрабатываются исключительно платежными системами в соответствии с их политиками.
